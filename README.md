# 광합성 산물 확인하기 · 가상 실험

햇빛을 받은 상추 잎과 어둠상자를 씌운 상추 잎을 에탄올로 탈색하고, 아이오딘-아이오딘화 칼륨 용액을 떨어뜨려 현미경으로 관찰하는 중학교 과학 가상 탐구 실험입니다. 태블릿·컴퓨터 브라우저에서 합니다.

**바로 가기:** https://kimju1416.github.io/photosynthesis-starch-kimcheon/

## 1단계 · 실험 설치

1. 상추 모종 2개를 끌어서 탁자 위에 놓습니다.
2. 둘 중 1개에 어둠상자를 씌웁니다.
3. 햇빛을 끌어서 하늘에 놓습니다.
4. 「24시간 두기」를 누르면 오른쪽 위 시계가 돌며 24시간이 지납니다.

## 2단계 · 실험 과정과 현미경 관찰

5. 에탄올 병을 끌어서 시험관 A, B에 에탄올을 넣습니다.
6. 상추 잎 A(햇빛을 받은 잎), B(햇빛을 받지 않은 잎)를 각각 시험관에 넣습니다. 시험관 옆 말풍선에 현미경으로 본 잎 세포가 나옵니다.
7. 시험관을 뜨거운 물이 든 비커에 넣으면 잎이 탈색되고, 말풍선 속 세포의 엽록체 색도 빠집니다.
8. 상추 잎을 페트리 접시로 옮깁니다.
9. 용액 병을 눌러 스포이드를 들고, 잎을 누르면 용액이 떨어집니다. 햇빛을 받은 잎은 엽록체가 있던 자리가 청람색으로 바뀌고, 햇빛을 받지 않은 잎은 변화가 없습니다.

## 3단계 · 탐구 결과

왼쪽 현미경 관찰 그림을 보고 오른쪽 질문에 답합니다.

- 관찰 결과: 햇빛을 받은 잎 조각·받지 않은 잎 조각 (청람색 / 변화 없음) 고르기
- 미리 알아두기: 아이오딘-아이오딘화 칼륨 용액은 ( 녹말 )과 반응하면 청람색 — 직접 입력
- 알 수 있는 사실: (햇빛을 받은 잎 조각 / 햇빛을 받지 않은 잎 조각)에서만 청람색 — 고르기
- 탐구 결론: 광합성 산물은 [포도당]이고, 포도당은 [녹말]로 바뀐다 — 흐린 글씨를 따라 입력하면 진하게 바뀜

맞히면 칸마다 「정답」이 표시되고, 모두 맞히면 크게 「정답입니다」가 나옵니다.

## 만든 방식

- `index.html` 파일 하나(HTML·CSS·JS), 빌드 도구 없음. 글꼴은 Pretendard.
- 배경과 기구 그림, 잎 세포 현미경 사진(`assets/`)은 이미지 생성 AI로 새로 만들었습니다. 탈색·청람색 사진은 같은 현미경 사진에서 색만 바꿔 엽록체 자리가 그대로 유지되게 했습니다.
- 참고한 예시: 광합성 산물 확인 가상 실험(Copywriter JaeG. Y &amp; AI)
